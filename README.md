# DJI Thermal Image Converter

基于 DJI Thermal SDK v1.8 的热成像图像批量转换工具，将 DJI 无人机拍摄的 R-JPEG 热成像图像转换为包含真实温度值的 TIFF 文件。

## 功能特点

- 🚀 **多线程并行处理**：支持多线程批量转换，处理速度快
- 🎯 **三种参数模式**：自动、手动、半自动三种模式灵活切换
- 📊 **自动参数读取**：自动从图像中提取嵌入的测量参数（发射率、距离、湿度、反射温度、环境温度）
- 🎛️ **半自动化处理**：支持部分参数自动读取，部分参数手动覆盖，灵活应对各种场景
- 🛡️ **智能容错机制**：参数读取失败时自动提示并提供多种处理方案
- 📍 **GPS 信息保留**：转换后的 TIFF 文件保留原始 GPS 坐标信息
- 🌡️ **真实温度值**：输出的 TIFF 文件每个像素值代表实际温度（摄氏度）

## 使用方法

### 快速开始

1. 将热成像图像放入 `input_dir` 目录
2. 修改 `main.py` 中的配置参数
3. 运行程序
```bash
python main.py
```

### 配置说明

在 `main.py` 文件底部修改以下配置：

```python
# ==================== 基础配置 ====================
INPUT_DIR = "input_dir"       # 输入文件夹路径
OUTPUT_DIR = "out_dir"        # 输出文件夹路径
MAX_WORKERS = 10              # 并行处理线程数

# ==================== 模式选择 ====================
# "auto"   = 自动模式: 全部参数从图像自动读取
# "manual" = 手动模式: 全部参数使用手动指定值
# "semi"   = 半自动模式: 部分自动，部分手动覆盖
PARAM_MODE = "auto"

# ==================== 手动参数值 ====================
# manual 模式: 全部使用这些值
# semi 模式: 只有 OVERRIDE_*=True 的参数使用这些值
MANUAL_EMISSIVITY = 0.95      # 发射率 [0.10, 1.00]
MANUAL_DISTANCE = 13.0        # 目标距离 (米) [1.0, 300.0]
MANUAL_HUMIDITY = 61.0        # 相对湿度 (%) [1.0, 100.0]
MANUAL_REFLECTION = 25.0      # 反射温度 (°C) [-40.0, 100.0]
MANUAL_AMBIENT = 22.0         # 环境温度 (°C) [-40.0, 80.0]

# ==================== 半自动模式覆盖开关 ====================
# 仅当 PARAM_MODE = "semi" 时生效
# True  = 使用上面的手动值覆盖
# False = 从图像自动读取
OVERRIDE_EMISSIVITY = False   # 是否覆盖发射率
OVERRIDE_DISTANCE = False     # 是否覆盖目标距离
OVERRIDE_HUMIDITY = False     # 是否覆盖相对湿度
OVERRIDE_REFLECTION = False   # 是否覆盖反射温度
OVERRIDE_AMBIENT = False      # 是否覆盖环境温度
```

### 三种参数模式

| 模式 | 设置 | 说明 | 适用场景 |
|------|------|------|----------|
| 🔵 自动模式 | `PARAM_MODE = "auto"` | 全部参数从每张图像自动读取 | 信任图像原始参数，无需修改 |
| 🟢 手动模式 | `PARAM_MODE = "manual"` | 所有图像使用统一的手动指定参数 | 需要完全覆盖原始参数 |
| 🟡 半自动模式 | `PARAM_MODE = "semi"` | 部分参数自动读取，部分参数手动覆盖 | 只需修改部分参数（如统一发射率） |

### 半自动模式详解

半自动模式是本工具的核心特性，允许你灵活控制每个参数的来源：

**使用场景示例：**

1. **统一发射率，其他参数保持原样**
   ```python
   PARAM_MODE = "semi"
   MANUAL_EMISSIVITY = 0.98
   OVERRIDE_EMISSIVITY = True    # 只覆盖发射率
   OVERRIDE_DISTANCE = False     # 其他参数从图像读取
   OVERRIDE_HUMIDITY = False
   OVERRIDE_REFLECTION = False
   OVERRIDE_AMBIENT = False
   ```

2. **修正环境参数，保留测量距离**
   ```python
   PARAM_MODE = "semi"
   MANUAL_HUMIDITY = 65.0
   MANUAL_AMBIENT = 28.0
   OVERRIDE_HUMIDITY = True      # 覆盖湿度
   OVERRIDE_AMBIENT = True       # 覆盖环境温度
   OVERRIDE_DISTANCE = False     # 距离从图像读取
   OVERRIDE_EMISSIVITY = False
   OVERRIDE_REFLECTION = False
   ```

3. **完全自定义组合**
   - 根据实际需求，任意组合自动读取和手动覆盖的参数
   - 每个参数独立控制，互不影响

### 测量参数说明

| 参数 | 说明 | 范围 |
|------|------|------|
| emissivity | 发射率，被测物体表面辐射能力 | [0.10, 1.00] |
| distance | 目标距离 (米) | [1.0, 300.0] |
| humidity | 相对湿度 (%) | [1.0, 100.0] |
| reflection | 反射温度 (°C)，周围环境反射温度 | [-40.0, 100.0] |
| ambient | 环境温度 (°C)，大气环境温度 | [-40.0, 80.0] |

## 输出格式

- 输出文件格式：32-bit TIFF
- 像素值：实际温度值（摄氏度）
- 元数据：保留原始 GPS 坐标信息

## 常见问题

**Q: 什么时候使用半自动模式？**
- 当你需要统一某些参数（如发射率），但保留其他参数的原始值时
- 当图像的部分参数不准确，需要手动修正时
- 当你想要批量修正环境参数（湿度、环境温度）但保留测量距离时

**Q: 图像参数无法读取怎么办？**
- 程序会自动检测并提供 4 种处理方案
- 可以选择跳过、手动输入备用参数、或切换到手动模式
- 建议先使用 `get_thermal_params.py` 检查单张图像

**Q: 如何查看图像的嵌入参数？**
- 使用 `get_thermal_params.py` 工具：
```bash
python get_thermal_params.py input_dir/your_image.JPG
```

**Q: 为什么转换失败？**
- 确保 DJI Thermal SDK 路径正确
- 确保输入图像是 DJI 热成像相机拍摄的 R-JPEG 格式
- 检查图像文件名不包含特殊字符
- 使用参数读取工具验证图像是否包含有效参数

**Q: 半自动模式和手动模式有什么区别？**
- 手动模式：所有图像使用完全相同的参数
- 半自动模式：可以为每个参数单独选择使用图像值还是手动值
- 半自动模式更灵活，适合大多数场景

**Q: 支持 Linux 吗？**
- 目前主要支持 Windows，Linux 需要使用对应的 SDK 库文件
